# For judges

**60 seconds.** Run `/abeyance demo` (or `python -m abeyance.demo`): no key, no setup, about a second. It
shows a scripted night run parking at `npm publish`, the card, a resume with the repo unchanged, a resume
refused after a commit, and a stranger refused. Then read `PROOF.md`'s matrix.

**3 minutes.** Add `FINDINGS.md` (the pre-registered corpora, the misses and false holds) and
`SDK_SURFACE.md` (every Hermes surface with file:line and what is not yet exercised).

**10 minutes.** Run `eval/campaign.py` against a Hermes checkout: 33 cases on the real cron scheduler and
agent loop. Read `abeyance/engine.py` top to bottom; it is Hermes-independent and 250 lines.

What is not shown yet: the real Telegram run and Desktop capture (see `PROGRESS.md`).
